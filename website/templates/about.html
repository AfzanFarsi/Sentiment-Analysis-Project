The model

Sentiscope classifies text into three sentiment classes — negative, neutral, positive — using a Logistic Regression model trained over TF-IDF features (unigrams and bigrams). It was chosen after being compared head-to-head against Random Forest and Multinomial Naive Bayes on macro-averaged F1 score.

The data

Training data is a labeled collection of short-form text posts, each tagged negative, neutral, or positive, along with contextual fields like time of day, age group, and country — used in the dashboard to see how sentiment breaks down across those dimensions, even though they turned out not to be strong predictors of sentiment themselves.

The dashboard

Every chart on the Dashboard page is built in Power BI from the model's predictions on a held-out test set — sentiment by time of day, by age group, by country, the vocabulary driving each class, and how the three candidate models stacked up against each other.

Tech stack

Python, scikit-learn, and pandas for the ML pipeline; Flask for this site; Power BI for the dashboard visuals.
